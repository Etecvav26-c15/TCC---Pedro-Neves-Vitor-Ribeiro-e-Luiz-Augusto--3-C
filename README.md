# 🏫 Sistema Escolar em Nuvem

O **Sistema Escolar em Nuvem** é uma plataforma web desenvolvida como Trabalho de Conclusão de Curso (TCC) do curso Técnico em Desenvolvimento de Sistemas da ETEC Vasco Antônio Venchiarutti.

O projeto tem como objetivo centralizar e facilitar o gerenciamento de informações acadêmicas e administrativas de instituições de ensino, conectando alunos, professores e coordenadores em um único ambiente digital integrado a um banco de dados em nuvem.

## Objetivos

- Facilitar o gerenciamento das informações acadêmicas.
- Centralizar os dados de alunos, professores, turmas e disciplinas.
- Otimizar os processos administrativos e pedagógicos.
- Garantir maior segurança e organização das informações.
- Proporcionar acesso rápido às informações escolares.
- Melhorar o acompanhamento do desempenho e da frequência dos alunos.

## Funcionalidades

- Sistema de Login e Logout.
- Cadastro e gerenciamento de usuários.
- Recuperação de senha.
- Autenticação e controle de permissões por perfil.
- Área exclusiva para alunos.
- Área exclusiva para professores.
- Área administrativa para coordenação.
- Consulta de notas e boletim escolar.
- Acompanhamento de frequência e faltas.
- Consulta de horários de aula.
- Emissão de declaração de matrícula em PDF.
- Registro de chamadas pelos professores.
- Lançamento e gerenciamento de notas.
- Criação e organização de planos de aula.
- Consulta de listas de alunos por turma.
- Cadastro e gerenciamento de turmas e disciplinas.
- Cadastro de professores e funcionários.
- Cadastro e gerenciamento de horários.
- Designação de professores para turmas e disciplinas.
- Geração de relatórios acadêmicos.

## Tecnologias Utilizadas

- PHP
- JavaScript
- Python
- Banco de Dados em Nuvem
